## 1. Was ist LilLIT?

Ein **Manifest für eine visionsbasierte Bildungsarchitektur**. LilLIT (abgeleitet von
„lillt“ = „leuchtet“) ist ein Konzept für ein Bildungssystem, das auf **individueller
Vision** statt auf standardisierten Curricula basiert.

## 3. Die Kernprinzipien

1. **Vision-basiert:** Das Bildungssystem orientiert sich an der individuellen Vision des
   Lernenden, nicht an standardisierten Curricula
2. **KI-Prothese:** KI dient als „Prothese“ — sie erweitert die Fähigkeiten des Lernenden,
   ersetzt sie aber nicht
3. **Barrieren-Neutralisierung:** Formale (Zugangs-, Prüfungs-) und physische Barrieren
   werden neutralisiert
4. **Intrinsische Motivation:** Die Motivation kommt von innen, nicht von außen
5. **Kreativität:** Kreativität ist das höchste Ziel

## 4. Bedeutung im Gesamtwerk

LilLIT ist die **Bildungs-Entsprechung** der anderen Konzepte:
- Wo andere Konzepte (02–07) Finanzinfrastrukturen beschreiben, beschreibt LilLIT eine
  **Bildungsinfrastruktur**
- Die **KI-Prothese**-Idee verknüpft es mit den KI-Konzepten (Konzept 10, 11)
- Die **Barrieren-Neutralisierung** spiegelt die „State-0-Compliance“ von PNIA (Konzept 01)
