## 1. Grundidee

Ein **no-code Pipeline-System**, das aus vorhandenen Repositories automatisch:
- **Skills-Graphen** und **Dokumentations-Graphen** erzeugt
- **Reverse Engineering** von Tools über Code-Analyse betreibt
- **Snapshots** als Artefakte speichert
- **Mermaid-/ASCII-Diagramme** generiert

Der Name **IHoLyCLaK** (auch „IHoLyCLaCK“) ist die Bezeichnung für diese Artefakt-Skills.

## 2. Funktionsweise

### Quellen
- **GitHub, GitLab, Hugging Face** (und weitere Repository-Quellen)
- Forks und Connections werden automatisch erkannt

### Verarbeitung
1. **Repository-Download** auf virtuellen Storage
2. **Code-Analyse** (Reverse Engineering): Struktur, Abhängigkeiten, Funktionen
3. **Graphen-Erzeugung:**
   - Skills-Graph (welche Fähigkeiten/Tools sind vorhanden?)
   - Docs-Graph (Dokumentations-Struktur)
4. **Diagramm-Generierung:** Mermaid- und ASCII-Diagramme
5. **Snapshot-Artefakte:** Zustände werden als Artefakte gespeichert

### „X-Ray“-Funktion
Das System kann Tools „durchleuchten“ (X-ray) und deren innere Struktur rekonstruieren —
ohne dass man sie in eine IDE packen muss.

## 3. Der neimo.-Anhang (IHoLyCLaCK . Juradiscution - NEIMO)

Eine E-Mail (TXT-Datei) von **neimo.** (Trial):
- Free neimo. API Key mit 100 Research Requests
- Zugang zur **Children's Online Safety Regulatory Database** (200+ Märkte)
- Nutzung: im Browser ODER als API-Key in Claude, Cursor, Manus oder jedem MCP-Client
- Hinweis: Einige Keys waren wegen eines Bugs nicht angekommen

**Einordnung:** Der neimo.-Zugang ist ein **regulatorischer Daten-Connector** (Kinder-Online-
Sicherheit), der über MCP in die IHoLyCLaK-Pipeline angebunden werden kann.
